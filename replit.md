# Моря Туманного Севера

Игровой проект о морском приключении в эпоху раннего Средневековья в странах Северного моря; рабочий источник состояния — `.studioigor/`.

## Запуск и работа

- Тесты: `./scripts/with-rust-toolchain.sh cargo test`
- Linux: `./scripts/with-rust-toolchain.sh cargo build --release`
- Web: `bash scripts/build-web.sh`
- Android APK: `bash scripts/build-android-apk.sh`
- Предпросмотр Web запускается управляемым артефактом Replit и обслуживается Rust-сервером.
- Игровой код и сборка не должны зависеть от Node.js, npm или pnpm.
- Цели сборки: Linux для внутренних проверок, WebAssembly для браузера и Android APK для пользовательских тестов. Windows пока не собираем, но избегаем платформенно-зависимого кода.
- Игровой рендер реализуется на Rust без игрового движка; Web собирается через `wasm-pack`/`wasm-bindgen`.
- Для сборки APK пользователь выбрал Rustroid; приложение работает локально на Android, поэтому вызвать его сборку из Replit нельзя.
- Для APK из Replit используется `bash scripts/build-android-apk.sh`: `cargo-apk` собирает тот же Rust NativeActivity-проект как замену недоступному здесь Rustroid. Выходной пакет подписан тестовым debug-ключом, не релизным.

## Технологии проекта

- Игровой пакет: Rust stable; Linux, WebAssembly и Android NativeActivity.
- Браузерная игра: рендер, игровое состояние, ввод и создание интерфейса на Rust; HTML/CSS — статические ресурсы, локальный сервер написан на Rust.
- В игровом репозитории нет Node.js, npm, pnpm, TypeScript/TSX, React или Expo.
- API-сервер, песочница макетов и общие библиотеки — отдельные локальные инструменты Replit, не нужны игре и не включаются в Git или публикацию.

Игровой артефакт создан. Браузер запускает Rust/WASM; Rust создаёт интерфейс, обрабатывает ввод и формирует SVG-сцену. Не подключай API или базу данных к игре без функции, которой действительно нужна серверная часть.

## Карта проекта

- `artifacts/api-server/` — локальный, необязательный API-инструмент Replit; игра его не использует.
- `artifacts/mockup-sandbox/` — локальный инструмент предпросмотра; игра его не использует.
- `.studioigor/` — локальные концепция, решения, этапы, исследования и референсы; не включать в Git.
- `.agents/` и `.local/` — служебные файлы агента и навыки; не включать в Git или публикацию.

## Решения по архитектуре

- Рабочее название: «Моря Туманного Севера».
- Игрок управляет Торфинном Рататоск, будущим Карлсефни; действие происходит до получения им этого прозвища.
- Плавание и корабли обеспечивают мобильность; главные столкновения проходят на суше. До половины игрового времени может занимать сухопутная игра.
- Камера в свободной игре ограниченно наклоняется; дальний обзор моря — строго сверху. Вид сбоку допускается только в диалогах.
- Пользователь выбрал Rust и целевые платформы Linux, Web и Android; Windows отложена, но должна оставаться возможной.
- Техника срезов и движок должны быть проверены прототипом; не менять язык или целевые платформы.
- В мобильном интерфейсе Web и Android обязательно должны быть экранные органы управления курсом (рулевое весло) и скоростью.
- В HUD используется исходная иконка Compass из раннего интерфейса; вся иконка поворачивается по курсу, цветной стрелки нет.

## Важные особенности

- Три присланных изображения — визуальные референсы, а не утверждённые игровые ассеты.
- Пользователь предложил получать боковую поверхность из цветных граней векторных срезов. Проверить это одним стеком в отдельной сцене; три ортогональных набора не считать обязательными.
- Сборки для Linux, Web и Android — отдельные артефакты из общей кодовой базы Rust; Linux-бинарник нельзя напрямую встраивать в браузер или Android.
