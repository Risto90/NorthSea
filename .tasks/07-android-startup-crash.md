## Что и зачем
Пользователь сообщил, что установленное Android-приложение закрывается сразу после запуска. Исправление следует за проверкой совместимости обновления в #26 и не ждёт предварительного подтверждения сбоя в GitHub Actions.

## Готовый результат
- Причина падения устранена.
- Закрыть Issue после локальной проверки запуска установленного приложения.
- Если сбой повторится только в APK, собранном GitHub Actions, считать это проблемой GitHub-сборки и исправлять её в задаче #27; повторное подтверждение для закрытия этой задачи не требуется.

## Вне объёма
- Проверки всех остальных пакетов и настройка публикации.
