## Что и зачем
Android воспринимает новый APK как конфликтующий пакет вместо обновления установленной игры.

## Готовый результат
- Причина конфликта подтверждена сравнением предыдущего и нового APK.
- Новые APK устанавливаются поверх предыдущей сборки с постоянным ключом без удаления приложения и пользовательских данных.
- Подпись стабильна между релизами, а versionCode увеличивается только для успешно опубликованной версии.
- В первом релизе с постоянным ключом пользователей предупреждают, что старые APK нельзя обновить и потребуется однократная переустановка, способная удалить локальные данные.

## Вне объёма
- Смена application ID.
