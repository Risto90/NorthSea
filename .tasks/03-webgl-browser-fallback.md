## Что и зачем
Сохранить WebGPU основным графическим API сайта, но добавить WebGL как резерв для браузеров, где WebGPU отсутствует, и как режим, который пользователь может выбрать в настройках веб-версии.

## Готовый результат
- Сайт сначала запускает WebGPU, а при его отсутствии предлагает или автоматически запускает WebGL.
- В настройках браузерной игры можно явно переключаться между WebGPU и WebGL; выбор сохраняется.
- При недоступности обоих API показывается понятное сообщение без бесконечной загрузки.
- Обе реализации используют общий Rust-код игры и одинаковые мобильные/настольные элементы управления.
- Проверены браузерные сборки и сценарии WebGPU, WebGL и отсутствия обоих API; новый релиз не создаётся.

## Вне объёма
- Нативные Vulkan-настройки Linux и Android.
- Изменение игрового содержимого, публикация нового релиза или сборка Windows.
- Игровые движки и отдельная реализация игры на TypeScript.
