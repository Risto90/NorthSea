## Что и зачем
Добавить Vulkan как отдельный нативный графический API для Linux и Android. При автоматическом выборе игра проверяет доступное оборудование и предпочитает Vulkan на совместимом GPU; пользователь может принудительно выбрать Vulkan или WebGPU в настройках.

## Готовый результат
- Linux и Android обнаруживают доступность Vulkan при запуске и выбирают Vulkan, если устройство его поддерживает; иначе используют WebGPU.
- В настройках нативной игры доступны режимы «Автоматически», «Только Vulkan» и «Только WebGPU»; выбор сохраняется.
- Принудительный режим Vulkan не переключается незаметно на WebGPU, если адаптер не поддерживает Vulkan, и показывает понятное сообщение.
- В диагностике можно определить выбранный API и графический адаптер.
- Проверены нативные сборки Linux и Android без выпуска нового релиза.

## Вне объёма
- WebGL и настройки графики в браузере.
- Сборка Windows.
- Игровой движок и автоматическое создание новых релизов.
